# Cloud Boots

Wear cloud boots and you can stand, walk and run on top of the clouds (y 193; Bedrock draws them at 192, and standing there was inside them). Crouch to fall through, and landing on them never hurts.

Clouds are only drawn in the sky, so the script puts invisible barrier blocks at y 192 under anyone wearing the boots near cloud height, and takes them out again once nobody needs them (also after a restart). It never replaces a real block.

Get them with `./mc kit cloud-boots` (boots plus scaffolding to climb up), or craft them: two white wool over two feathers, like boots.
